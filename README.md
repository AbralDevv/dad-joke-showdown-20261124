One dad joke, at most 200 characters, written by `main.ts` to `entry.txt`:

> Why did the coffee file a police report? It got mugged.

## Run

```sh
node main.ts
```

Node 22.18 or later, stdlib only, no network. The program writes
`entry.txt` to `$MAKEFUN_OUTPUT_DIR` when set, otherwise `/output`,
falling back to `./output`.
